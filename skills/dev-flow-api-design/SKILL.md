# dev-flow-api-design

先读[共享契约](../dev-flow/references/workflow.md)，定位目标项目、轮次及现有产物或批次。

显式读取全部前序产物。按原型动作和业务规则设计接口，明确操作人、前置条件、输入输出、状态变化和失败行为。已有消费者受影响时说明兼容方式。选一条关键操作展示用户动作 → 系统读写 → 失败或重复操作时的可见结果，并指回数据和接口设计章节。对未决冲突给出建议和影响。
