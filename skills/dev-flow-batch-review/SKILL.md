# dev-flow-batch-review

先读[共享契约](../dev-flow/references/workflow.md)，定位目标项目、轮次及现有产物或批次。

核对目标、差异、复验步骤和实际证据。明确建议通过、返工或调整后续批次，并显式展示依据、失败及未验证项。需要独立审查时提供目标、验收条件、差异与证据，由审查方自行追查。先记待验收，讨论后写入结论与下一步。返工回本批，接受后标记已通过。后续批次依用户指令开始。

若仍有影响本批的设计决定待讨论，保留待讨论停点，并说明决定解决后要复验什么。验收结论应对应当前改动和证据。全轮约定范围均已验收时，按共享契约收尾并更新轮次索引。
