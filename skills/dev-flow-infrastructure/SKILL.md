# dev-flow-infrastructure

先读[共享契约](../dev-flow/references/workflow.md)，定位目标项目、轮次及现有产物或批次。

核对批次和依赖，标记进行中。新项目按确认架构建立最小可运行骨架，按需接通配置、迁移、测试和日志。已有项目实际运行适用的启动和检查，复用可用能力，只补当前阻塞。记录命令、观察结果、失败、未验证项和阻塞。实质架构冲突按共享状态规则提出初判并讨论。完成本批验证后按[验收 Skill](../dev-flow-batch-review/SKILL.md)准备初判，停在验收点。
