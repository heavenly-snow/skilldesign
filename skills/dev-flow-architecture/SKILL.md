# dev-flow-architecture

先读[共享契约](../dev-flow/references/workflow.md)，定位目标项目、轮次及现有产物或批次。

显式读取全部前序产物，以已澄清 PRD 为依据。结合仓库现状定义模块边界、关键数据流及必要的基础设施。先出架构初稿，再挑出会影响用户体验、数据一致性、系统边界或返工成本的决定。逐项列出推荐、证据、可行备选、代价和改选条件。将讨论结论写回相应决策，保留未决事项。
