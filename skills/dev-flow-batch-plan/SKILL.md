# dev-flow-batch-plan

先读[共享契约](../dev-flow/references/workflow.md)，定位目标项目、轮次及现有产物或批次。

结合项目现状和设计自主查找依据。先排 B00 及各业务批次和依赖。以可独立验收的行为切批，结合返工成本，允许跨前后端及数据库。细化最近一批的范围和复验方法，其余先记录目标与依赖。用[批次模板](references/batch-template.md)创建或更新记录，显式展示整份初版、切分依据和调整建议。将讨论结果写回。

调整已有计划时，保留历史批次的证据与讨论结论。受新增或变更范围影响的已验收结果应标明影响，在新批次安排复验。规划完成后停在计划讨论点。
