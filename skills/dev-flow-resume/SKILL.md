# dev-flow-resume

先读[共享契约](../dev-flow/references/workflow.md)，定位目标项目、轮次及现有产物或批次。

定位轮次和停点。设计阶段查看登记的产物及待决项，恢复相应设计 Skill。开发阶段对照批次记录、仓库差异、现有产物和验证证据，区分已实现、已验证和已接受。记录漂移与修正依据。待讨论或待验收时重新呈现已记录的初判，缺失时先补初判。进行中则在已授权范围内继续当前批。待执行时报告依赖与推荐下一步，按用户指令执行。
